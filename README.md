## Overview

I am an **Artificial Intelligence & Data Science** student at **Vishwakarma Institute of Technology (VIT Pune)** working across **developer tooling**, **runtime execution visualizers**, and **data systems with verifiable provenance**.

My engineering work focuses on making complex software observable — whether parsing ASTs to render live memory mutations, isolating execution sandbox environments in Web Workers, or structuring verifiable audit trails across healthcare and decentralized protocols.

## Engineering Principles

- **Observability by Design:** Code should be inspectable. Whether parsing ASTs to reveal runtime execution or generating clear state diagrams, transparency leads to better engineering.
- **Data Provenance First:** Data without origin tracking and transformation history cannot be verified. Systems must preserve a verifiable audit trail.
- **Asynchronous Execution:** Heavy computation belongs in dedicated background workers and async queues to ensure steady, uninterrupted 60 FPS interfaces.
